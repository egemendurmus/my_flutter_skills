# Deliverable template

## Mode and objective
CREATE or EVOLVE; one-sentence scope.

## Evidence and decisions
Repository branch / inspected files, known constraints, architecture choice, alternatives rejected.

## Files
Exact relative file tree, then complete file contents per path. Avoid ellipses and pseudocode. For large changes, provide a self-contained vertical slice and explicitly defer the rest.

## Commands
Dependency installation, code generation, format, analyze and test commands with correct working directory.

## Verification
A table with check, command, PASS/FAIL/NOT RUN/BLOCKED and concise evidence. Never claim tests passed without execution.

## Risks and rollback
Data compatibility, native integrations, network/security issues, rollback strategy and next smallest change.
